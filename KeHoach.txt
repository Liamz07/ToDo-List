To-Do List App

Chức năng cơ bản phát triển:
- Add Task: Thêm công việc mới
- View Tasks: Hiển thị danh sách công việc
- Complete Task: Đánh dấu công việc hoàn thành
- Delete Task: Xóa công việc
- Edit Task: Chỉnh sửa 
- Search: Tìm kiếm công việc theo tên
- Filter: 
+ All: Tất cả
+ Active: Chưa hoàn thành
+ Completed: Đã hoàn thành
- Task Achieved: 
+ Total: 10
+ Active: 4
+ Completed: 6
- Lưu dữ liệu: Sử dụng localStorage để khi user đóng trình duyệt rồi mở lại, task vẫn còn
- Priority: Cho phép đặt mức độ High, Medium, Low
- Đặt hạn hoàn thành:
+ VD: Task: Học JavaScript, Due: 10/09/2026

Những chức năng phát triển sau: 
👤 Đăng ký / đăng nhập
🔐 Authentication / Session
☁️ Lưu task trên Database
🔄 Đồng bộ dữ liệu giữa nhiều thiết bị
🏷️ Category / Tag
📅 Calendar
🔔 Notification / Reminder
↕️ Drag & Drop để sắp xếp task
🌙 Dark / Light mode
📱 Responsive cho mobile
🔗 REST API
👥 Chia sẻ task với người khác

Những chức năng tự suy nghĩ ra: 
- Thay đổi quote theo từng ngày
