## 📖 Usage

1. Enter a task in the input field.
2. Click **Add Task**.
3. Click the checkbox to complete a task.
4. Click **Edit** to modify a task.
5. Click **Delete** to remove a task.
6. Use the filter buttons to filter tasks.

## ⚙️ How It Works

The application uses JavaScript to manage tasks.

- User enters a task.
- JavaScript creates a task object.
- The task is displayed on the page.
- Tasks are stored in Local Storage.
- When the page is reloaded, tasks are loaded from Local Storage.
